# Python Course - UPJV

Matériaux de cours Python pour l'Université Picardie Jules Verne (UPJV).

## 📚 Structure du cours

Le cours est organisé en **9 travaux dirigés (TDs)** de 2 heures chacun, plus **2 travaux à la maison** en binôme.

### Travaux Dirigés (en classe)

| TD | Thème | Contenu |
|----|-------|---------|
| **TD06** | Les bases de Python et les listes | Variables, types, listes, indexation, slicing |
| **TD07** | Fonctions, paquets et NumPy | Fonctions, modules, NumPy, arrays |
| **TD08** | Matplotlib, Dictionnaires et Pandas | Visualisations, dictionnaires, manipulation de données |
| **TD09** | Logique, flux de contrôle et étude de cas | Conditions, boucles, filtrage, statistiques sur les pirates |

### Travaux à la maison (en binôme)

- **Enquête sur les films Netflix** : Analysez un dataset de films Netflix avec les techniques vues en TD6-TD9

## 🚀 Comment utiliser ce cours

### Pour les étudiants

1. **Accéder aux notebooks** :
   - Chaque TD contient un lien direct pour ouvrir le notebook dans Google Colab
   - Voir le README.md de chaque TD pour le lien

2. **Ressources** :
   - Les slides (PDF) et infographies (PNG) générées depuis NotebookLM se trouvent dans les dossiers `presentations/` et `images/`
   - Chaque TD inclut un README.md avec ses objectifs et contenus

3. **Présence et QCM** :
   - Les TDs se font **en présentiel**
   - Feuille de présence Google Forms à remplir en classe
   - QCM disponible dans Google Classroom

4. **Travaux à la maison** :
   - À faire **en binôme**
   - À rendre **avant la date limite** communiquée
   - Voir les détails dans le README.md du travail correspondant

### Pour le professeur

- Ajouter les notebooks `.ipynb` dans chaque dossier TD
- Mettre à jour les dossiers `resources/` avec les fichiers de données
- Configurer Google Classroom avec les liens et questionnaires
- Gérer les Google Forms pour la présence et les QCM

## 📊 Plateforme d'apprentissage

- **GitHub** : Stockage du contenu

- **Google Classroom** : Interface principale pour les étudiants
