# TD07 : Fonctions, paquets et Numpy

## Objectifs du TD
- Créer et utiliser des fonctions en Python
- Découvrir et utiliser les paquets/modules

## Contenu
- Définition et appel de fonctions
- Paramètres et retours de fonction
- Imports et paquets Python
- Introduction à NumPy
- Arrays NumPy et opérations vectorisées
