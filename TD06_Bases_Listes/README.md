# TD06 : Les bases de Python et les listes

## Objectifs du TD
- Maîtriser les bases du langage Python
- Comprendre et manipuler les listes
- Apprendre les opérations essentielles sur les listes

## Contenu
- Variables et types de données
- Opérations de base en Python
- Listes : création, indexation, slicing
- Méthodes des listes
- Boucles et listes

## Fichiers
- `notebook.ipynb` : Notebook interactif Google Colab
- `presentations/` : Slides générées depuis NotebookLM
- `images/` : Infographies générées depuis NotebookLM
- `resources/` : Fichiers de données et ressources du TD
